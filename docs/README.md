# مشروع: نظام إدارة مكتبة رقمية

- اللقب: [واغد]
- الفوج: [1]

## وصف المشروع
يهدف هذا المشروع إلى تطوير نظام مكتبة رقمي بسيط باستخدام مفاهيم البرمجة كائنية التوجه (OOP) في Java. يقوم النظام بإدارة الكتب، المستعيرين، وعمليات الإعارة والاسترجاع.

## أهداف المشروع
- استخدام مفاهيم الـ OOP (التغليف، الوراثة، تعدد الأشكال)
- تجربة استخدام Git و GitHub
- إنشاء واجهة نصية بسيطة لتجربة النظام

## تشغيل المشروع
1. افتح المشروع في أي بيئة Java مثل IntelliJ أو VS CODE
2. شغّل الملف `LibraryApp.java`
3. اتبع التعليمات من الواجهة النصية

## تصميم الكود
- `Book.java`: يمثل كتابًا فرديًا
- `Borrower.java`: يمثل مستعير
- `BorrowingProcess.java`: يتعامل مع عملية الإعارة
- `LibraryApp.java`: واجهة المستخدم والتحكم الكامل

## ملاحظات
- النظام لا يستخدم قاعدة بيانات، فقط تخزين في الذاكرة
- المشروع مصمم للتوسعة مستقبلاً ليشمل خصائص أكثر
